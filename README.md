## 🚖 GrandTaxi.ma

**GrandTaxi.ma** is a responsive web application designed to simplify seat reservations for intercity Grand Taxis in Morocco.

The platform allows users to search for available trips, reserve one or multiple seats, manage baggage options, complete secure online payments, and receive PDF tickets. The application also provides real-time seat availability updates to prevent double booking and includes dedicated spaces for administrators and drivers.

### ✨ Main Features

* User authentication and reservation history
* Search trips by departure and arrival cities
* Automatic selection of the first available taxi
* Seat reservation with real-time availability updates
* Double booking prevention using WebSockets
* Baggage management with automatic price calculation
* Secure online payments with Stripe
* PDF ticket generation using domPDF
* REST API for reservation and trip management
* Admin dashboard for managing cities, taxis, trips, and reservations
* Driver dashboard for monitoring reservations and seat availability

### 🛠️ Technologies Used

* **Backend:** Laravel, REST API
* **Frontend:** Blade, Tailwind CSS, JavaScript
* **Database:** MySQL
* **Real-Time Communication:** Laravel Reverb, WebSockets
* **Payment Gateway:** Stripe
* **PDF Generation:** domPDF
* **Tools:** Git, GitHub, Jira

### 🎯 Project Goal

The main goal of this project is to digitalize the intercity taxi reservation process in Morocco by providing a modern, secure, and user-friendly platform for travelers, drivers, and administrators.
